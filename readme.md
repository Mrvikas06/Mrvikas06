**Focus:** ML fundamentals · Python/ML implementation · React · Node.js · Socket.IO

###  [AEGIS](https://github.com/Mrvikas06/Aegis-ai)

Generative-AI stadium operations project built during a 48-hour hackathon, combining a full-stack interface with LLM-powered workflows.

**Focus:** LLM applications · LangChain · API integration · Full-stack engineering

###  [ResumeIQ](https://github.com/Mrvikas06/ResumeIQ)

Resume intelligence platform that classifies resumes with TF-IDF and Logistic Regression, extracts skills, and scores resume-to-job-description similarity.

**Focus:** Applied machine learning · NLP features · scikit-learn · FastAPI · Docker

###  [LuminAI](https://github.com/Mrvikas06/LuminAI)

Adaptive AI learning platform that generates personalized curricula, maps knowledge prerequisites, tutors learners, and adapts quizzes to areas of weakness.

**Focus:** LLM engineering · Gemini API · React · Vite · adaptive learning workflows

###  [BiasGuard AI](https://github.com/Mrvikas06/BiasGuard-AI)

AI fairness auditing dashboard with bias analysis, counterfactual what-if simulations, and Gemini-generated explanations and recommendations.

**Focus:** Responsible AI · fairness analysis · explainability · React · Gemini API

###  [Agentic Carbon Tracker](https://github.com/Mrvikas06/Agentic-Carbon-Tracker)

Carbon-tracking project using an AI-powered workflow with FastAPI, Streamlit, and the Gemini API.
